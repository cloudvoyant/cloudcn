`Field` wires a label, control, and helper/error text together with correct `aria` (the control's `aria-describedby` and invalid state are handled by Ark). Built on [Ark UI `field`](https://ark-ui.com/docs/components/field) and [`fieldset`](https://ark-ui.com/docs/components/fieldset).

## API Reference

### Field

#### Props

Accepts all [Ark `FieldRoot` props](https://ark-ui.com/docs/components/field) (`invalid`, `disabled`, `required`, `ids`, …) plus `className`/`class`.

### FieldLabel

#### Props

Accepts all [Ark `FieldLabel` props](https://ark-ui.com/docs/components/field) plus `className`/`class`.

### FieldPrefix / FieldSuffix

#### Props

Plain `<span>` slots rendered inside the `Field`'s flex row. Use them for units (`$`, `%`) or icons (search) that hug the control. Styled with `fieldPrefixBase`/`fieldSuffixBase` (flex, muted, `[&_svg]` sizing).

### FieldHint

#### Props

Accepts all [Ark `FieldHelperText` props](https://ark-ui.com/docs/components/field) plus `className`/`class`.

### FieldError

#### Props

Accepts all [Ark `FieldErrorText` props](https://ark-ui.com/docs/components/field) plus `className`/`class`.

### FieldRequiredIndicator

#### Props

Accepts all [Ark `FieldRequiredIndicator` props](https://ark-ui.com/docs/components/field) plus `className`/`class`. Defaults to rendering `*`.

### FieldGroup

See [FieldGroup](/helix/components/field-group) for grouping Fields or Checkboxes.

## Accessibility

Ark wires `for`/`id`, `aria-describedby`, and `aria-invalid` between the label, control, helper, and error text.

## Theming

No theme extension — uses `--foreground`, `--muted-foreground`, `--destructive`.
