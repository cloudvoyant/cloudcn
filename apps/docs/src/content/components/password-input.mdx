`PasswordInput` is a password field with a visibility toggle. Built on [Ark UI password-input](https://ark-ui.com/docs/components/password-input). Pair with `Field` for label/error.

## API Reference

### PasswordInput

#### Props

Accepts all [Ark `PasswordInputRoot` props](https://ark-ui.com/docs/components/password-input) plus `className`/`class`.

### PasswordInputControl / PasswordInputInput / PasswordInputVisibilityTrigger / PasswordInputIndicator

Accept all corresponding Ark props plus `className`/`class`. `PasswordInputInput` also takes `size` (`'sm' | 'md' | 'lg'`). Render the eye/eye-off icons as `PasswordInputVisibilityTrigger` children — the trigger toggles the input `type` automatically.

## Accessibility

Ark wires `aria` between the control and the visibility trigger (`aria-label` on the trigger is set by the example). The input remains a native `<input type="password">` until toggled.

## Theming

No theme extension — uses `--input`, `--ring`, `--muted-foreground`, `--destructive`.
