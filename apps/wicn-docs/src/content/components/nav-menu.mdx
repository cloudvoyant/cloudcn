The NavMenu composes a row of menu items whose triggers open positioned dropdown panels. It is a thin wrapper over [Ark UI `navigation-menu`](https://ark-ui.com/docs/components/navigation-menu), styled like [shadcn's navigation menu](https://ui.shadcn.com/docs/components/base/navigation-menu), sharing the `navMenuTriggerStyle` cva + part classes from `wicn-core`. Use the framework selector in the top-right to switch between implementations.

## API Reference

All parts accept standard element attributes plus `className`/`class`, merged via `cn` with the shared part classes.

### NavMenu

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `density` | `'relaxed' \| 'compact'` | `'relaxed'` | Trigger size. `compact` compacts the menu triggers (`h-8`, tighter padding, `text-xs`) via `data-density` on the root. |

Accepts all [Ark `NavigationMenuRoot` props](https://ark-ui.com/docs/components/navigation-menu) plus `className`/`class` and `density`. Renders the `List` region plus the shared `ViewportPositioner`/`Viewport` that dropdown content portals into.

### NavMenuTrigger

#### Props

Accepts all [Ark `NavigationMenuTrigger` props](https://ark-ui.com/docs/components/navigation-menu). Applies `navMenuTriggerStyle()` and renders a chevron that rotates when its item is open.

### NavMenuItem

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | Identifies the item. |
| `disabled` | `boolean` | `false` | Disables the item. |
| `variant` | `'default' \| 'link'` | `'default'` | Trigger treatment. `link` styles the item's trigger/link as a text link — transparent background, `text-muted-foreground` with `hover:text-foreground` and `data-[state=open]:text-primary` — matching a top nav of plain links, via `data-variant` on the item. Combine with `NavMenuTrigger asChild` to render the trigger as an actual `<a>`. |

### NavMenuContent

#### Props

Accepts all [Ark `NavigationMenuContent` props](https://ark-ui.com/docs/components/navigation-menu). Renders the dropdown panel; portal into the shared viewport is handled by Ark.

### NavMenuLink

#### Props

Accepts all [Ark `NavigationMenuLink` props](https://ark-ui.com/docs/components/navigation-menu). Renders an `<a>` styled as a menu link.

### Other parts

`NavMenuList`, `NavMenuViewport`, `NavMenuViewportPositioner`, `NavMenuIndicator` — each accepts its native element props plus `className`/`class`.

## Accessibility

Follows the [Navigation Menu WAI-ARIA pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/). The underlying Ark `navigation-menu` provides hover/click triggers with `openDelay`/`closeDelay`, arrow-key roving, `Escape` dismissal, and the `menu`/`menuitem` roles — wicn never hand-rolls these. The trigger chevron is `aria-hidden`.

## Theming

No theme extension is required — all styling uses existing tokens (`bg-popover`, `text-muted-foreground`, `bg-accent`, `border-border`, `--radius-*`), light and dark.
