## API Reference

The React and Svelte components accept `variant`, `size`, and `className`/`class`, plus standard button attributes and all [Ark toggle](https://ark-ui.com/docs/components/toggle) `ToggleRoot` props.

### ToggleButton

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'outline'` | `'default'` | Visual emphasis. |
| `size` | `'default' \| 'sm' \| 'lg'` | `'default'` | Height of the button. |
| `pressed` | `boolean` | — | Controlled pressed state. |
| `defaultPressed` | `boolean` | `false` | Initial state when uncontrolled. |
| `onPressedChange` | `(details: PressedChangeDetails) => void` | — | Fires when pressed state changes. |
| `className` / `class` | `string` | — | Merged via `cn` with the variant classes. |

### ToggleButtonIndicator

#### Props

Accepts all [Ark `ToggleIndicator`](https://ark-ui.com/docs/components/toggle) props. Renders its children only when the button is pressed; pass the `fallback` prop to render content in the unpressed state.

## Accessibility

Follows the [Button WAI-ARIA pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/). The underlying Ark `toggle` sets `aria-pressed` automatically and supports keyboard activation with `Space` and `Enter`.
