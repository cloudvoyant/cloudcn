## Accessibility

Ark renders a native `<textarea>`. Invalid state is announced via `aria-invalid` when inside a `Field`; pair with `FieldLabel`/`FieldError` for full labelling.

## Theming

No theme extension — uses `--input`, `--ring`, `--destructive`, `--muted-foreground` tokens, light and dark.
