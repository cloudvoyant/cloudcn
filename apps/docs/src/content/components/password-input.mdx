## API Reference

### PasswordInput

A single self-contained component — renders the control, the input, and the built-in visibility toggle (eye/eye-off) in one tag. The toggle flips the input `type` automatically.

| Prop          | Type                   | Default  | Description                          |
| ------------- | ---------------------- | -------- | ------------------------------------ |
| `size`        | `'sm' \| 'md' \| 'lg'` | `'md'`   | Input height.                        |
| `placeholder` | `string`               | —        | Passed to the input element.         |
| `disabled`    | `boolean`              | `false`  | Disables the input.                  |
| `autoComplete`| `string`               | `'off'`  | Passed to the input element.         |
| `name`        | `string`               | —        | Passed to the input element.         |

Also accepts all [Ark `PasswordInputRoot` props](https://ark-ui.com/docs/components/password-input) (`value`, `defaultValue`, `onValueChange`, …) plus `className`/`class`.

### usePasswordInput

Returns the Ark password-input context (`usePasswordInputContext`): `{ value, visible, setValue, setVisible, ... }` — use it to build custom visibility toggles or controlled values.

## Accessibility

Ark wires `aria` between the control and the visibility trigger (`aria-label` on the trigger is set by the example). The input remains a native `<input type="password">` until toggled.

## Theming

No theme extension — uses `--input`, `--ring`, `--muted-foreground`, `--destructive`.
