The Item is a content box used throughout the examples. The `surface` variant adds a rounded border and themed surface color — used inside `Stack`/`HStack`/`VStack`; the default `plain` variant has no color or boundary — used inside `Container`/`Row`/`Col`.

## API Reference

### Item

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'plain' \| 'surface'` | `'plain'` | `surface` adds a rounded `border border-border bg-card text-card-foreground` (themed); `plain` is square-cornered with no color or boundary. |
| `className` / `class` | `string` | — | Merged last via `cn`; override growth, padding, rounding, or background with Tailwind classes. |

## Accessibility

Renders a native `<div>`, so it requires no roles or keyboard handling.
