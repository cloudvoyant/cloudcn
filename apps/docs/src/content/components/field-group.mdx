`FieldGroup` groups Fields or Checkboxes under a `FieldGroupLegend` (a native `<fieldset>`/`<legend>`). Built on [Ark UI fieldset](https://ark-ui.com/docs/components/fieldset).

## Accessibility

`FieldGroup` renders a native `<fieldset>`/`<legend>`, so the group label is announced for every control inside it and focus moves between the group's controls in DOM order. Keyboard: `Tab` moves into the group, `Space` toggles a focused checkbox.

## Theming

No theme extension — uses `--foreground`, `--muted-foreground`, `--destructive`.
