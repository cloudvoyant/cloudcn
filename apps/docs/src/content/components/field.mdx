`Field` wires a label, control, and helper/error text together with correct `aria` (the control's `aria-describedby` and invalid state are handled by Ark). `FieldSet` groups related fields in a `<fieldset>` with a legend. Built on [Ark UI `field`](https://ark-ui.com/docs/components/field) and [`fieldset`](https://ark-ui.com/docs/components/fieldset), sourced from [Shark UI](https://shark.vini.one/docs/components/field).

## API Reference

### Field

#### Props

Accepts all [Ark `FieldRoot` props](https://ark-ui.com/docs/components/field) (`invalid`, `disabled`, `required`, `ids`, …) plus `className`/`class`.

### FieldLabel

#### Props

Accepts all [Ark `FieldLabel` props](https://ark-ui.com/docs/components/field) plus `className`/`class`.

### FieldHelper

#### Props

Accepts all [Ark `FieldHelperText` props](https://ark-ui.com/docs/components/field) plus `className`/`class`.

### FieldError

#### Props

Accepts all [Ark `FieldErrorText` props](https://ark-ui.com/docs/components/field) plus `className`/`class`.

### FieldRequiredIndicator

#### Props

Accepts all [Ark `FieldRequiredIndicator` props](https://ark-ui.com/docs/components/field) plus `className`/`class`. Defaults to rendering `*`.

### FieldSet

#### Props

Accepts all [Ark `FieldsetRoot` props](https://ark-ui.com/docs/components/fieldset) plus `className`/`class`.

### FieldSetLegend / FieldSetHelper / FieldSetError

Accept all corresponding Ark `Fieldset*` props plus `className`/`class`.

## Accessibility

Ark wires `for`/`id`, `aria-describedby`, and `aria-invalid` between the label, control, helper, and error text. `FieldSet` renders a native `<fieldset>`/`<legend>`.

## Theming

No theme extension — uses `--foreground`, `--muted-foreground`, `--destructive`.
