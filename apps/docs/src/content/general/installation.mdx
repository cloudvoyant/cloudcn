## Workspace packages

The library ships three npm packages:

- `@cloudvoyant/vertex-ui` — shared interfaces, cva variants, and the shadcn-style theme.
- `@cloudvoyant/vertex-react` — React components (Ark UI based).
- `@cloudvoyant/vertex-svelte` — Svelte components (Ark UI based).

## Install

```bash
pnpm add @cloudvoyant/vertex-ui @cloudvoyant/vertex-react
# or for Svelte
pnpm add @cloudvoyant/vertex-ui @cloudvoyant/vertex-svelte
```

Import the theme once in your app's global CSS:

```css
@import 'tailwindcss';
@import '@cloudvoyant/vertex-ui/theme.css';
/* Registers the vertex-ui component class strings (cva variants + framework
   classes) with Tailwind via @source self-scanning — no manual @source needed. */
@import '@cloudvoyant/vertex-ui/components.css';
```
