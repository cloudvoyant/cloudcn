## Workspace packages

The library ships three npm packages:

- `cloudcn-core` — shared interfaces, cva variants, and the shadcn-style theme.
- `cloudcn-react` — React components (Ark UI based).
- `cloudcn-svelte` — Svelte components (Ark UI based).

## Install

```bash
pnpm add cloudcn-core cloudcn-react
# or for Svelte
pnpm add cloudcn-core cloudcn-svelte
```

Import the theme once in your app's global CSS:

```css
@import 'tailwindcss';
@import 'cloudcn-core/theme.css';
/* Tailwind doesn't scan node_modules by default — point at cloudcn-core so its
   cva class strings (bg-primary, h-10, …) get generated. Path is relative to
   your global CSS file. */
@source '../../node_modules/cloudcn-core/dist';
```
