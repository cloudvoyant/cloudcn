The Center centers its child both horizontally and vertically using flexbox (`align-items: center` and `justify-content: center`). It is implemented in both React and Svelte on top of Ark UI's factory, sharing the `centerBase` class from `cloudcn-core`.

## API Reference

The Center exposes no manual sizing or display props — use `className`/`class`, which is merged last via `cn` so Tailwind classes override the defaults.

### Center

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` / `class` | `string` | — | Merged via `cn` with `centerBase` (`flex items-center justify-center`). Pass `inline-flex` to make it inline. |

## Accessibility

Renders a native `<div>`, so it requires no roles or keyboard handling.
