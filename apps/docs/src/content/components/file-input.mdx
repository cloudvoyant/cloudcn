`FileInput` is a drop-zone file input with an item list and delete/clear controls. Built on [Ark UI file-upload](https://ark-ui.com/docs/components/file-upload). Pair with `Field` for label/error.

## API Reference

### FileInput

#### Props

Accepts all [Ark `FileUploadRoot` props](https://ark-ui.com/docs/components/file-upload) (`accept`, `multiple`, `maxFiles`, `files`, `onFileChange`, …) plus `className`/`class`.

### FileInputDropzone / FileInputTrigger / FileInputItemGroup / FileInputItem / FileInputItemName / FileInputItemSizeText / FileInputItemDeleteTrigger / FileInputClearTrigger

Accept all corresponding Ark `FileUpload*` props plus `className`/`class`. `FileInputItemGroup` renders the item list container; `FileInputItem` requires an `index` (or a `file`).

## Accessibility

Ark exposes a hidden native file input and wires the dropzone/trigger `aria` and keyboard activation. Each delete trigger carries an `aria-label`.

## Theming

No theme extension — uses `--input`, `--ring`, `--muted-foreground`, `--destructive`.
