cloudcn is a small UI component library for React and Svelte, built on Ark UI primitives with a shared theme and shared cva variants in `cloudcn-core`.

Every component is implemented in both frameworks from the same variant definitions, so React and Svelte components stay visually and behaviorally in sync.

Use the framework selector in the top-right to switch between the React and Svelte implementations on each component page.
