## API Reference

The React and Svelte components accept the same `variant`, `color`, and `size` props, plus standard button attributes (`type`, `disabled`, `className`/`class`).

### Button

#### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `'solid' \| 'outline' \| 'text'` | `'solid'` | Fill style. |
| `color` | `'primary' \| 'secondary' \| 'success' \| 'danger' \| 'warn' \| 'info'` | `'primary'` | Palette color. |
| `size` | `'sm' \| 'md' \| 'lg' \| 'icon'` | `'md'` | Button size. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button type. |
| `disabled` | `boolean` | `false` | Disables the button. |
| `className` / `class` | `string` | — | Merged via `cn` with the variant classes. |

## Accessibility

Renders a native `<button>` element via Ark's factory, so it gets keyboard support, focus styling, and button role announcement for free.

**Keyboard support:**

- `Space` / `Enter` — activates the button.
- `Tab` — moves focus to/from the button.
