## CSS variables

The theme in `@cloudvoyant/helix` matches [shadcn/ui's theming](https://ui.shadcn.com/docs/theming) exactly: semantic tokens such as `--background`, `--foreground`, `--primary`, and `--secondary` are defined under `:root` for light mode and overridden under `.dark`. On top of the shadcn token set, helix adds `--success`, `--danger`, `--warn`, and `--info` (each with a `-foreground`) for semantic status colors used by `Button` and `Badge`, plus the standard font stacks — marked as helix additions in `theme.css`.

## Theme presets

Beyond the base shadcn "Neutral" palette, `@cloudvoyant/helix` ships over fifty shadcn-compatible theme presets in `@cloudvoyant/helix/themes.css`. Each preset is a `.theme-{name}` block for light mode and a `.theme-{name}.dark` block for dark mode that overrides the same CSS variables:

```css
@import 'tailwindcss';
@import '@cloudvoyant/helix/theme.css';
@import '@cloudvoyant/helix/themes.css';
```

Apply a preset by adding its class to `<html>` — e.g. `class="theme-catppuccin"`. Any token a preset doesn't override (for example a helix status color) falls back to the base `:root` / `.dark` values. The docs site's theme selector demonstrates the full list.

## Dark mode

Set the `dark` class on `<html>` for dark mode, and use a `theme-{name}` class to pick a preset. The docs site persists both — a `helix:color-mode` preference (`light` / `dark` / `system`) and a `helix:theme` preset — and honors `prefers-color-scheme` by default.
