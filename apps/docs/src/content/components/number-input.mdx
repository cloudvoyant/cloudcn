`NumberInput` is a numeric field with a drag-to-adjust scrubber, keyboard editing, clamping, and `Intl` formatting. Built on [Ark UI `number-input`](https://ark-ui.com/docs/components/number-input).

## API Reference

### NumberInput

#### Props

Accepts all [Ark `NumberInputRoot` props](https://ark-ui.com/docs/components/number-input) (`min`, `max`, `step`, `value`, `onValueChange`, `precision`, `formatOptions`, `allowMouseWheel`, …) plus `className`/`class`.

### NumberInputControl / NumberInputInput / NumberInputScrubber / NumberInputValueText

Accept all corresponding Ark props plus `className`/`class`. `NumberInputInput` also takes `size` (`'sm' | 'md' | 'lg'`). The scrubber renders inside the control by default and drags vertically to adjust the value. The left/right increment/decrement steppers are removed; use arrow keys on the input for step changes.

## Accessibility

Ark provides the spin-button role, keyboard increment/decrement (arrow keys), and `aria-valuemin`/`aria-valuemax`/`aria-valuenow`.

## Theming

No theme extension — uses `--input`, `--ring`, `--muted-foreground`.
