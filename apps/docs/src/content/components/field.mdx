`Field` wires a label, control, and helper/error text together with correct `aria` (the control's `aria-describedby` and invalid state are handled by Ark). Built on [Ark UI `field`](https://ark-ui.com/docs/components/field) and [`fieldset`](https://ark-ui.com/docs/components/fieldset).

## API Reference

### Field

| Prop | Type | Default |
| --- | --- | --- |
| `invalid` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `ids` | `FieldRootProps['ids']` | — |
| `className` | `string` | — |

### FieldLabel

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | — |

### FieldPrefix

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | — |

Plain `<span>` slot — use for units (`$`, `%`) or icons. Accepts standard `span` attributes.

### FieldSuffix

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | — |

Plain `<span>` slot rendered after the control.

### FieldControl

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | — |

Bordered box carrying the field's border + focus ring — wrap `FieldPrefix` + a ghost `Input` + `FieldSuffix` inside it.

### FieldHint

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | — |

### FieldError

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | — |

### FieldRequiredIndicator

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | — |

Defaults to rendering `*`.

### FieldGroup

See [FieldGroup](/helix/components/field-group).

### useField

Returns the Ark field context (`useFieldContext`): `invalid`, `disabled`, `required`, `getLabelProps`, `getInputProps`, … — use it to build custom controls that render inside `Field`.

## Accessibility

Ark wires `for`/`id`, `aria-describedby`, and `aria-invalid` between the label, control, helper, and error text.

## Theming

No theme extension — uses `--foreground`, `--muted-foreground`, `--destructive`.
